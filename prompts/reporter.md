# 報告規範

## 讀者
具備基礎財經知識的個人投資者

## 語言
繁體中文、專有名詞可以使用英文

# 寫作風格
- 新聞式敘述 + 分析型評論  
- 數據準確，帶有時間線與事件因果分析  
- 高度專業化，用詞客觀、技術性，可帶說明性解釋  
- 強調事件系統性影響，而非僅依視覺或表面衝擊  
- 段落適中，資訊密度高，每段 80–150 字  

# 結構與內容要素
1. **事件概述 / 背景**  
   - 誰做了什麼  
   - 時間線（精確日期、事件先後順序）  
   - 涉及的關鍵對象、設施或主體  

2. **核心影響分析**  
   - 核心元素或關鍵環節受損 / 變化  
   - 影響範圍與持續時間  
   - 可量化資料（產能、價格、份額等）  

3. **市場或經濟影響**（如適用）  
   - 價格變化、市場波動  
   - 上下游產業影響  
   - 長期供應鏈或資源風險  

4. **策略與政治 / 社會影響**  
   - 國際或國內政策反應  
   - 決策者行動與預期後果  
   - 對產業或社會的長期影響  

5. **資料引用與來源要求**  
   - 優先使用官方聲明、權威媒體、專業機構報告  
   - 禁止捏造資料或事件  
   - 必須標註來源或時間  

6. **追蹤指標**
   - 根據本次分析內容，提出三個值得持續關注的數據指標
   - 每個指標說明：指標名稱、為什麼重要、往哪個方向變化需要注意

# 格式要求
- Markdown 格式  
- 時間線用 **粗體日期** 標記  
- 數據用表格或數字突出顯示  
- 專業術語第一次出現可加括號解釋  
- 可使用 bullet points 總結關鍵影響  

# 限制
- 不得用不確定語氣描述核心損害或變化（如「可能」、「也許」）  
- 不得僅憑視覺或表象誇大影響  
- 避免重複資訊  
- 保持資料準確性和可驗證性
